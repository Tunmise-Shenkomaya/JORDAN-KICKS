# Jordan Kicks Website 👟

A modern and responsive website for showcasing **Jordan sneakers**.  
The site includes multiple pages with a clean UI/UX design.  

## 🚀 Features
- Responsive **Home**, **Products**, **About**, and **Contact** pages  
- Sleek and user-friendly **UI/UX design**  
- Organized folder structure with media assets  
- Built with **HTML, CSS, and JavaScript**  

## ⚠️ Note
The **e-commerce functionality (cart & checkout)** is not yet implemented — current focus is on **design and layout**.   

## 🛠️ Technologies Used
- HTML5  
- CSS3 (Responsive design)  
- JavaScript
